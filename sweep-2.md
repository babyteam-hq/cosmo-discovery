# Cosmo sweep 2: wider territory (2026-10-31, cloud worker cosmo-sweep-2, R-116)

Same conventions as `sweep.md`: a falsifiable question, the public data, the literature check (one search each, "memory"
marks a reference recalled, not re-found), a detectability estimate, Nov x Det = Rank. The first sweep was Pantheon+
heavy; this one goes to DESI, the Cosmicflows-4 catalogue itself, GWTC-4, the pulsar timing arrays, CMB lensing, Quaia
and CatWISE, eROSITA, Gaia, and the NGC 1052 trail of dark-matter-free dwarfs (the founder's lead). Literature check by
a search agent (WebSearch extended + arXiv pages), ranking and run order by the worker; rows run are in `results.md`
(R-116 section). Row 39 (ZTF replication of the dust slope) was already done by R-115 (`results.md` "3 on ZTF").

Run order (rank, then cost): 31, 32, 36, 35, 33 (the trail, `trail_ngc1052.py`, minutes), 7, 6, 9 (CF4 distances vs the
dust-map difference and hemisphere zero points, `cf4_dust.py`), 38 (stellar maps, Mudur 2023 and Zhou 2024, at the SN
positions, folded into `dust_settle.py`'s part a), 21 and 23 (Quaia dust template, Quaia redshift errors vs sky), 26
(eRASS1 cluster n(z) vs latitude), 17 (SN residuals vs CMB kappa), 4 and 37 (DESI n(z) and galaxy colours vs dust, big
downloads, last).
