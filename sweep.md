# Cosmo sweep: cheap tests on public data, literature-checked (2026-10-31, cloud worker cosmo-sweep, R-115)

Each row: a falsifiable question, the dataset (downloadable), the literature check (one web/arXiv search each; "memory"
marks a reference recalled, not re-found), a detectability estimate, and a rank = novelty x detectability. Scores 0-3.
Detectability is expected S/N for a plausible-size effect, from sample size and scatter. Ranked rows run first
(`results.md`). Already ruled out before this sweep and not listed: Pantheon+ dipole/quadrupole/frames/redshift
shells, Pantheon+ x CMB-lensing kappa (`README.md`, `LOG.md`).

Conventions for the SN tests: Pantheon+SH0ES distances (`Pantheon+SH0ES.dat`) with the full STAT+SYS covariance,
calibrators out, z>0.01, flat LCDM Om=0.334, generalised least squares (as `frames.py`).
