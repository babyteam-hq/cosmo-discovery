# Proposed test: S8 and Omega_m from the DESI DR1 BGS void size function

Question: what do the abundances of voids as a function of size in the DESI DR1 Bright Galaxy Survey (z < 0.24) say about S8 and Omega_m? The void size function has been measured on the public DESI void catalogues but not fitted for cosmology. Measure S8-Omega_m with intervals.

Data: the public DESIVAST void catalogues (arXiv:2411.00148) from DESI DR1 BGS; the DESI DR1 BGS galaxy and random catalogues; AbacusSummit DESI-like mocks at several cosmologies.

Method: fixed before fitting: the void finder and catalogue (one of the DESIVAST finders as primary, a second as the check), the radius range, the theoretical model (the Vdn model with a tracer-bias calibration of the void radius, as in the BOSS void-size-function analysis), the calibration of that model on AbacusSummit mocks run through the same finder and selection, the likelihood. Errors from mocks; nulls: the model fitted to mocks at known cosmology recovers it.

Expected precision: S8 to about +-0.05 at fixed Omega_m; a consistency test against weak lensing and CMB.
