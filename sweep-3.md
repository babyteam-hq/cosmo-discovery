# Cosmo sweep 3: catalogue-level tests, under the blind-review gate (2026-10-31, cloud worker cosmo-sweep-5, R-119)

Same conventions as `sweep.md` and `sweep-2.md`: a falsifiable question, the public data (checked reachable from this network
before ranking), the literature check (two search agents, WebSearch extended + arXiv pages; "memory" marks a reference
recalled, not re-found), a detectability estimate, Nov x Det = Rank. New this time: Will's gate (`blind-review.md`). The top
five by rank went to a context-free Opus referee as a proposal alone in a file (question, data, method, precision; no
literature claims) before any computation; the verdict line is recorded verbatim in the "Gate" column and in `results.md`.
A "not novel" verdict kills the row.

Territory: the Cosmicflows-4 catalogue itself (not its reconstructed fields), CHIME Catalog 2 at fixed declination, the
localized FRBs, BOSS as an independent-photometry check of the DESI-stars dust pattern, and the suggestions in the brief
(Quaia/CatWISE, DESI BGS dipole, ACT DR6 x SNe, Gaia proper motions, FRB DM-z, CF4 catalogue tests, SN pairwise velocities),
each checked. Reachable from this network today: GitHub raw (Pantheon+, FRBs/FRB host compilation, SFD), data.desi.lbl.gov,
IRSA TAP (CatWISE2020), vizier.idia.ac.za (CF4, Quaia, Gaia DR3 qso_candidates, 2MRS, eRASS1), gaia.aip.de and the
Heidelberg GAVO TAP (Gaia DR3), assets.chime-frb.ca (Catalog 2), projets.ip2i.in2p3.fr (CF4 fields), data.sdss.org (BOSS/eBOSS
LSS), PLA, heasarc, datacentral. Not reachable: zenodo.org (403), gea.esac.esa.int (Gaia archive), edd.ifa.hawaii.edu, CDS
VizieR/ftp, github.com release assets, LAMBDA's ACT data directory (403; the product page loads), skyserver/CasJobs, MAST.
